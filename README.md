# Arcane vs. Steel — 2D Physics Auto-Battler

A visually rich 2D 1v1 physics-flavored auto-battler inspired by *Totally Accurate Battle Simulator (TABS)*. Two AI-controlled fighters (**Aethelgard the Warrior** vs. **Ignis Sol the Fire Mage**) battle automatically in a dark, atmospheric arena with procedural physics animations, dynamic lighting, real-time floor reflections, and cinematic ultimates.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/import?s=https%3A%2F%2Fgithub.com%2Fpandora523%2Farcane-vs-steel)

## Features
- **100% Procedural HTML5 Canvas Pipeline:** Additive lighting (`globalCompositeOperation = 'lighter'`), real-time vertically-flipped floor reflections, dynamic drop shadows, chromatic aberration, hit-stop freeze frames, and screen shake.
- **TABS-Style Spring/Wobble Physics:** Articulated limb rigging, spring-damper torso recoil, and Verlet-style flowing cape/robe physics.
- **Cinematic Ultimates:** **Heavenly Earthshatter** (Warrior) & **Meteor Cataclysm** (Fire Mage) with `0.25x` time dilation and arena dimming.
